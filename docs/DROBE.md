# Drobe - inventory Catalog

## Overview
Drobe is a simple, personal wardrobe management app that allows you to catalog your inventory items in an organized and easy-to-use format. This MVP focuses on adding and managing inventory items to help you track your wardrobe.

## Core Features

### 1. Add inventory Items
Add basic details for each inventory item:

- Name (e.g., "Red T-Shirt")
- Category (e.g., "Shirt", "Jeans", "Jacket")
- Image (photo of the item)

### 2. View inventory Items
Browse items added to your wardrobe in a simple list or grid view.

### 3. Edit/Remove Items
Easily update or remove items as your wardrobe changes.

### 4. Search
Quickly find inventory items by name or category.

## Simple UI
- Add Item Button: For quickly adding new inventory.
- Filter/Sort: A simple way to view items by category.
- Item Preview: Show images to identify items at a glance.
